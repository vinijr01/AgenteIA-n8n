# Agente IA para Atendimento Odontológico com n8n

## Sobre o Projeto

Este projeto consiste no desenvolvimento de um agente de Inteligência Artificial para atendimento automatizado via WhatsApp, criado utilizando **n8n**, **OpenAI**, **Redis**, **Easy Painel** e **Evolution API**.

O agente foi desenvolvido para simular o atendimento de uma clínica odontológica, realizando acolhimento inicial, identificação de necessidades do paciente e apresentação de informações sobre tratamentos de forma humanizada.

---

## Objetivo

O objetivo do projeto é demonstrar a aplicação de Inteligência Artificial Generativa integrada a ferramentas de automação para:

* Automatizar atendimentos via WhatsApp;
* Melhorar a experiência do paciente;
* Reduzir o tempo gasto com atendimentos repetitivos;
* Demonstrar o potencial de agentes inteligentes em processos empresariais.

## Funcionalidades Implementadas

### Atendimento Inteligente

* Recepção automática do paciente;
* Conversação natural utilizando IA;
* Identificação de necessidades do paciente;
* Coleta de informações básicas;
* Apresentação de tratamentos da clínica.

### Memória Conversacional

* Armazenamento do histórico utilizando Redis;
* Continuidade do contexto durante a conversa.

### Integração com WhatsApp

* Recebimento de mensagens;
* Processamento por IA;
* Resposta automática ao usuário.

---

## Funcionalidades em Desenvolvimento

* Integração completa com sistema de agendamento;
* Consulta automática de horários disponíveis;
* Agendamento e cancelamento de consultas;
* Painel administrativo para gestão dos atendimentos;
* Métricas e relatórios de conversas.

---

## Fluxo Simplificado

```text
WhatsApp
    ↓
Evolution API + Easy Painel (Servidor Hospedado)
    ↓
n8n
    ↓
OpenAI
    ↓
Redis (Memória)
    ↓
Resposta ao Usuário
```
